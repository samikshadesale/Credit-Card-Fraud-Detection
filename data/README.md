# Dataset

The Credit Card Fraud Detection dataset used in this project was obtained from Kaggle.

Dataset:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The original dataset is not included in this repository because of its large size.

The dataset contains anonymized transaction features such as V1-V28, Time, Amount, and Class.

Class:
- 0 = Normal transaction
- 1 = Fraudulent transaction
